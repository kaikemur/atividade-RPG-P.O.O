# 🎯 Objetivo

O principal objetivo é criar uma narrativa de batalha entre personagens usando classes e métodos, incentivando o aprendizado prático de P.O.O. por meio de um exemplo interativo.

# 🛠️ Tecnologias

 JavaScript — Linguagem usada para modelar personagens e simular rodadas de combate.

 Classes e Herança — Demonstra extensões de classes (Guerreiro, Mago) a partir de uma base (Personagem).

 Encapsulamento de atributos privados — Uso de campos privados para proteger o estado interno (como pontos de vida).

# 🕹️ O que o código faz

 O arquivo principal (rpg.js) cria dois personagens — um guerreiro e um mago — e simula várias rodadas de combate entre eles.
Cada personagem tem:

 Nome

 Poder de ataque

 Vida

 Atributos específicos (força ou magia)

 Em cada rodada, os personagens se atacam e o programa mostra:

* ✔ Dano causado
* ✔ Vida restante
* ✔ Estado de cada personagem (vivo ou derrotado)
